# Octopus B3 green identity

These are the approved v1.0.0 raster masters from the [Octopus brand kit](https://ads.weezboo.com/brand-kit/octopus/index.html), approved and exported on 2026-09-11. They are not vector artwork.

- `octopus-mark.png`: transparent emerald mascot, used in navigation and app chrome.
- `octopus-dark.png` and `octopus-light.png`: approved artwork for brand downloads.
- `../og-image.png`: the kit's unchanged 1200 × 628 dark landscape export.

App icons are size exports of the transparent mark, padded on Ink for maskable/home-screen use. Older logo URLs remain available for existing external links; new UI uses the assets here.

See the [brand guidelines](https://octopus-review.ai/brand) for colors, typography, usage rules, and licensed font downloads. The implementation lives in the [shared theme](../../app/globals.css) and [root layout](../../app/layout.tsx).
